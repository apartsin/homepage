# Building AI Textbooks: disk folder to source repo

Reference mapping of each textbook to its local disk folder and GitHub source repo.
Book source folders live under `E:\Projects\Books\<folder>`. Kept for cross-session
reference; stored under `_meta/` so the legacy Jekyll build does not publish it to the
public site. Machine-readable copy: [book-repos.json](book-repos.json).
