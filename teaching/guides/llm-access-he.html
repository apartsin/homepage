English עברית

לפרויקטי הקורס מוקצה בדרך כלל תקציב OpenRouter קטן לכל פרויקט, אבל אפשר גם לעבוד עם מודלי שפה בחינם. הנה מאיפה לקבל גישה, ואיך לשמור על עלויות נמוכות.

מאיפה לגשת למודלי שפה

API אחד למודלי ענן רבים, או הרצת מודלים מקומית ללא עלות.

  • OpenRouter

    מומלץ · מודלים חינמיים

    מומלץ לגישה למודלי שפה בענן. API אחד למודלים מסחריים ופתוחים רבים, כך שאפשר להחליף מודלים בלי לשנות את היישום. הוא גם מספק מודלים חינמיים לפיתוח ולניסויים.

  • Ollama

    מקומי · ללא עלות API

    הריצו מודלים כמו Llama, Qwen, Gemma ואחרים מקומית על המחשב שלכם, ללא עלות API. שימושי במיוחד לפיתוח ולבדיקות.

שמרו על עלויות ה-LLM נמוכות

עלויות ה-API יכולות לצמוח במהירות בעיבוד מאגרי נתונים גדולים. כמה כללים פשוטים עוזרים.

  • נפו באגים קודם על מדגם קטן. אל תריצו 10,000 דוגמאות לפני שווידאתם שה-pipeline עובד נכון על 10–50.
  • השתמשו במודלים זולים או חינמיים בשלב הפיתוח, ובמודלים יקרים יותר רק כשצריך.
  • אגדו בקשות (batching) בעיבוד מאגרי נתונים גדולים. ל-OpenRouter יש Batch API לשליחת בקשות רבות יחד.
  • השתמשו ב-prompt caching כאשר בקשות רבות חולקות אותן הוראות או הקשר ארוכים. ראו את מדריך ה-Prompt Caching של OpenRouter.
  • שמרו על פרומפטים ופלטים קצרים ככל האפשר. בדרך כלל משלמים גם על טוקני קלט וגם על טוקני פלט.
  • עקבו אחר השימוש והעלות תוך כדי פיתוח, במקום לגלות את העלות אחרי ניסוי גדול.

כלל אצבע: פתחו ונפו באגים בקטן ובזול, והגדילו את ההיקף רק אחרי שהכול עובד.
